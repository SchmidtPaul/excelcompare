# excelcompare: Compare Excel Files Cell by Cell

Compare Excel files (.xlsx) at the cell level, detecting differences in
content across all cells including titles, footnotes, and annotations.
Built on 'tidyxl' for comprehensive cell-by-cell comparison that goes
beyond tabular data to capture every cell in a worksheet.
